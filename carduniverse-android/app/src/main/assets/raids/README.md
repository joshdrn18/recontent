# Raid artwork slots

Optional WebP images, preferably landscape 16:9, 1280 × 720 or smaller. Names:

- ancient-dragon.webp
- frost-titan.webp
- ashen-queen.webp
- storm-colossus.webp
- eclipse-seraph.webp
- celestial-arbiter.webp

If a file is missing or unreadable, its unique native placeholder is shown. Both the raid encounter and strike dialog use the same slot. Artwork files require rebuilding the APK. No game data changes.
